Promptly — prompt generator for Claude, GPT and Gemini

Describe what you want to make in plain language. Promptly writes a prompt using the conventions of the assistant you name — XML sections for Claude, direct Markdown instructions for GPT, front-loaded context for Gemini — and you paste it in yourself.

Ten templates cover marketing copy, professional email, social posts, code review, research summaries, brainstorming, technical explainers, product briefs, meeting agendas and data analysis. No account, no sign-up, and nothing you type is stored on a server unless you ask for it.
